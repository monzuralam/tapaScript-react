# Cars

**Cars** is a basic React.js project that demonstrates how to break down a design into reusable components while maintaining a top-level tree hierarchy.

---

## Installation

Follow these steps to set up the project:

1. Clone this repository:
   ```bash
   git clone https://github.com/monzuralam/tapaScript-react
   ```
2. Switch to the `cars` branch:
   ```bash
   git checkout cars
   ```
3. Install the dependencies using Yarn:
   ```bash
   yarn
   ```
4. Start the development server:
   ```bash
   yarn dev
   ```
5. Access react project on the browser:
   ```bash
   http://localhost:5173/
   ```
